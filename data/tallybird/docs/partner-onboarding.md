# Partner onboarding checklist

Use this checklist when a new enterprise customer signs.

1. Create the account in the admin console and invite the customer's admins.
2. Issue the partner a v1 API key from the admin console and share it through the secure vault link.
3. Send them the API Quickstart and book a 30-minute integration call.
4. Add their webhook endpoint and send a test `invoice.created` event.
5. Hand over to Support with a summary in the CRM.
